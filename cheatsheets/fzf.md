# 🔍 fzf 치트시트 (퍼지 검색)

> 어디서든 목록을 빠르게 좁혀 고르는 도구. 셸에 단축키로 연결돼 있음.

## 셸 단축키 (바로 됨)
| 키 | 동작 |
|----|------|
| `Ctrl+R` | 명령 히스토리 검색 |
| `Ctrl+T` | 파일/경로 골라서 현재 줄에 삽입 |
| `Alt+C` | 하위 폴더 골라서 cd |

## fzf 창 안에서
| 키 | 동작 |
|----|------|
| (타이핑) | 실시간으로 목록 좁히기 |
| `위/아래` 또는 `Ctrl+j/k` | 항목 이동 |
| `Enter` | 선택 |
| `Tab` | 다중 선택 표시 |
| `Esc` / `Ctrl+C` | 취소 |
| `Ctrl+/` | 미리보기 창 토글 |

## 검색 문법 (입력칸에서)
| 입력 | 의미 |
|------|------|
| `foo bar` | foo **그리고** bar 둘 다 포함 |
| `'foo` | 정확히 foo 포함 |
| `^foo` | foo 로 시작 |
| `foo$` | foo 로 끝 |
| `!foo` | foo 제외 |

## 파이프로 직접 쓰기
```bash
fd . | fzf              # 파일 골라서 출력
git branch | fzf        # 브랜치 고르기
nvim "$(fzf)"           # 고른 파일을 nvim으로 열기
kill -9 $(ps -ef | fzf | awk '{print $2}')   # 프로세스 골라 종료
```
