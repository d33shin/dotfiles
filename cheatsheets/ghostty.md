# 👻 Ghostty 치트시트

> 터미널 에뮬레이터 자체. 설정: `~/.config/ghostty/config`

## 탭 / 창
| 키 | 동작 |
|----|------|
| `Ctrl+Shift+t` | 새 탭 |
| `Ctrl+Shift+n` | 새 창 |
| `Ctrl+Shift+w` | 탭/창 닫기 |

## 분할 (Ghostty 자체 분할)
| 키 | 동작 |
|----|------|
| `Ctrl+Shift+o` | 오른쪽으로 분할 |
| `Ctrl+Shift+e` | 아래로 분할 |
| `Ctrl+Alt+방향키` | 분할 사이 이동 |
| `Ctrl+Shift+Enter` | 분할 전체화면 토글 |

> 💡 분할은 보통 **tmux로 하는 걸 추천** (어느 기계서나 동일하니까). Ghostty 분할은 로컬 전용.

## 복사 / 붙여넣기
| 키 | 동작 |
|----|------|
| `Ctrl+Shift+c` | 복사 |
| `Ctrl+Shift+v` | 붙여넣기 |
| (드래그) | 자동 복사 (copy-on-select 켜둠) |

## 폰트 / 설정
| 키 | 동작 |
|----|------|
| `Ctrl+=` / `Ctrl+-` | 폰트 크게 / 작게 |
| `Ctrl+Shift+,` | 설정 리로드 (config 수정 후) |

## 현재 설정 (config)
- 테마: Kanagawa Wave
- 폰트: JetBrainsMono Nerd Font 13
- 드래그 선택 시 자동 복사
