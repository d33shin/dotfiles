# 🌿 lazygit 치트시트 (git 화면)

> 실행: git 폴더에서 `lg` (또는 `lazygit`). 종료: `q`

## 패널 이동
| 키 | 동작 |
|----|------|
| `Tab` 또는 `←/→` | 패널 전환 (Files/Branches/Commits/Stash) |
| `↑/↓` 또는 `j/k` | 항목 이동 |
| `?` | 현재 화면 단축키 도움말 |
| `q` | 종료 |

## 스테이징 / 커밋 (Files 패널)
| 키 | 동작 |
|----|------|
| `Space` | 파일 스테이지 / 언스테이지 |
| `a` | 전체 스테이지 |
| `Enter` | 파일 열어 줄 단위로 스테이지 |
| `c` | 커밋 (메시지 입력) |
| `C` | 에디터로 커밋 메시지 작성 |
| `d` | 변경 버리기 (discard) |

## 브랜치 (Branches 패널)
| 키 | 동작 |
|----|------|
| `Space` | 해당 브랜치로 체크아웃 |
| `n` | 새 브랜치 |
| `M` | 현재로 머지 |
| `d` | 브랜치 삭제 |

## 원격 (push / pull)
| 키 | 동작 |
|----|------|
| `P` (대문자) | push |
| `p` (소문자) | pull |
| `f` | fetch |

## 커밋 히스토리 (Commits 패널)
| 키 | 동작 |
|----|------|
| `Enter` | 커밋 내용 보기 |
| `g` | reset 메뉴 |
| `r` | 커밋 메시지 수정(reword) |
| `s` | 아래 커밋과 합치기(squash) |

## 기타
| 키 | 동작 |
|----|------|
| `Enter` | 들어가기 / `Esc` 나오기 |
| `z` / `Ctrl+z` | undo / redo (git 동작) |
| `+` / `_` | 패널 크게/작게 |
