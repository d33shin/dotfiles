# 📝 Neovim 치트시트

> leader 키 = **Space**. `Space` 누르고 기다리면 메뉴(which-key)가 뜬다.

## 모드 (제일 기본)
| 키 | 동작 |
|----|------|
| `i` | 입력(insert) 모드 진입 |
| `Esc` 또는 `jk` | 일반(normal) 모드로 복귀 |
| `v` / `V` | 비주얼 선택 / 줄 선택 |
| `:` | 명령 모드 (`:w` 저장, `:q` 종료) |

## 파일 / 검색
| 키 | 동작 |
|----|------|
| `Space e` | 파일 트리 토글 |
| `Space f f` | 파일 이름으로 찾기 |
| `Space f g` | 내용(텍스트) 검색 |
| `Space f b` | 열린 버퍼 목록 |
| `Space f r` | 최근 파일 |
| `Space f x` | 진단(에러) 목록 |

## 저장 / 종료
| 키 | 동작 |
|----|------|
| `Space s` | 저장 (저장 시 prettier 자동 정렬) |
| `:w` | 저장 |
| `:q` | 종료 / `:q!` 저장 안 하고 종료 / `:wq` 저장 후 종료 |
| `:qa` | 모든 창 종료 |

## 이동 (normal 모드)
| 키 | 동작 |
|----|------|
| `h j k l` | 좌 하 상 우 |
| `w` / `b` | 다음/이전 단어 |
| `0` / `$` | 줄 처음/끝 |
| `gg` / `G` | 파일 맨 위/맨 아래 |
| `Ctrl+d` / `Ctrl+u` | 반 페이지 아래/위 |
| `Ctrl+h/j/k/l` | 분할창·tmux 패널 이동 |

## 편집
| 키 | 동작 |
|----|------|
| `dd` / `yy` / `p` | 줄 잘라내기 / 복사 / 붙여넣기 |
| `u` / `Ctrl+r` | 실행취소 / 다시실행 |
| `Space d` | 레지스터 오염 없이 삭제 |
| (비주얼) `p` | 복사본 유지하며 덮어쓰기 |

## 코드 (LSP)
| 키 | 동작 |
|----|------|
| `gd` | 정의로 이동 |
| `gr` | 참조 찾기 |
| `K` | 문서/타입 보기 |
| `Space r n` | 이름 변경 (전체) |
| `Space c a` | 코드 액션 (자동수정) |
| `Space c f` | 수동 포매팅 |
| `[d` / `]d` | 이전/다음 에러 |

## 자동완성 (insert 중)
| 키 | 동작 |
|----|------|
| `Ctrl+Space` | 자동완성 띄우기 |
| `Tab` / `Shift+Tab` | 다음/이전 후보 |
| `Enter` | 선택 |

## 창 분할
| 키 | 동작 |
|----|------|
| `Ctrl+w s` / `Ctrl+w v` | 가로 / 세로 분할 |
| `Ctrl+w w` | 다음 창으로 |
| `Ctrl+h/j/k/l` | 방향 이동 |
