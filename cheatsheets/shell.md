# 🐚 셸 (bash) 치트시트

## 별칭 (이 환경에 설정됨)
| 별칭 | 실제 | 동작 |
|------|------|------|
| `ll` | `eza -l --git` | 자세한 목록 |
| `la` | `eza -la` | 숨김파일 포함 |
| `lt` | `eza --tree` | 트리 보기 |
| `ls` | `eza --icons` | 아이콘 목록 |
| `cat` | `bat` | 컬러 + 줄번호 |
| `vim`/`vi` | `nvim` | |
| `lg` | `lazygit` | git 화면 |
| `z 이름` | zoxide | 폴더 점프 |

## 커서 이동 (입력 중)
| 키 | 동작 |
|----|------|
| `Ctrl+a` / `Ctrl+e` | 줄 처음 / 끝 |
| `Alt+f` / `Alt+b` | 단어 앞 / 뒤 |
| `Ctrl+w` | 앞 단어 삭제 |
| `Ctrl+u` / `Ctrl+k` | 커서 앞/뒤 전부 삭제 |
| `Ctrl+l` | 화면 청소 (clear) |

## 히스토리 / 검색
| 키 | 동작 |
|----|------|
| `Ctrl+R` | **fzf 히스토리 검색** (타이핑 → Enter) |
| `Ctrl+T` | **fzf 파일 선택** (경로 삽입) |
| `Alt+C` | **fzf 폴더 이동** |
| `위/아래` | 이전 명령 |
| `!!` | 직전 명령 다시 |
| `!$` | 직전 명령의 마지막 인자 |

## 프로세스
| 키 | 동작 |
|----|------|
| `Ctrl+C` | 중단 |
| `Ctrl+Z` | 일시정지(백그라운드) |
| `fg` / `bg` | 다시 앞/뒤로 |
| `Ctrl+D` | 셸 종료 (EOF) |

## 자주 쓰는
```bash
exec bash      # 설정 다시 읽기(새 셸)
which 명령      # 명령 경로
type 명령       # 별칭/함수인지 확인
```
