# 🚀 시작하기 (제일 먼저 읽기)

## 매일 쓰는 흐름
1. **Ghostty** 열기 (프롬프트 = starship)
2. `z 프로젝트이름` → 폴더 점프
3. `nvim .` → 에디터 열기
4. 작업 → `Space s` 저장 → `:q` 종료

## 치트시트 보는 법
```
cheat            # 메뉴에서 고르기 (타이핑해서 좁히고 Enter)
cheat nvim       # nvim 치트시트 바로
cheat tmux       # tmux 치트시트 바로
```
보는 중: 화살표/스페이스로 스크롤, `q`로 닫기.

## 막힐 때 3가지 탈출구
- nvim에서 길 잃음 → `Esc` 여러 번 → `:q!` (저장 안 하고 종료)
- tmux에서 길 잃음 → `Ctrl+b` 떼고 `d` (분리, 터미널로 복귀)
- 명령 모름 → `cheat` 로 해당 도구 열기
