# 🪟 tmux 치트시트

> **prefix = `Ctrl+b`** (떼고 다음 키). 일부는 prefix 없이 동작.

## 패널 이동 (prefix 없이 — 바로)
| 키 | 동작 |
|----|------|
| `Ctrl+h / j / k / l` | 왼/아래/위/오른쪽 패널 (nvim과 연동) |
| `Alt+u` | 스크롤 모드 진입 |

## 패널 (화면 쪼개기)
| 키 | 동작 |
|----|------|
| `Ctrl+b` `%` | 좌우로 분할 |
| `Ctrl+b` `"` | 위아래로 분할 |
| `Ctrl+b` `x` | 현재 패널 닫기 |
| `Ctrl+b` `z` | 현재 패널 전체화면 토글 |
| `Ctrl+b` `空格` (space) | 패널 배치 변경 |

## 윈도우 (= 탭)
| 키 | 동작 |
|----|------|
| `Ctrl+b` `c` | 새 윈도우 |
| `Ctrl+b` `n` / `p` | 다음 / 이전 윈도우 |
| `Ctrl+b` `0~9` | 번호로 이동 |
| `Ctrl+b` `,` | 윈도우 이름 변경 |
| `Ctrl+b` `&` | 윈도우 닫기 |

## 세션 (작업 통째로 보관)
| 키 | 동작 |
|----|------|
| `Ctrl+b` `d` | 분리(detach) — 작업 살려두고 빠져나옴 |
| `tmux ls` | 세션 목록 (셸에서) |
| `tmux attach` | 다시 붙기 |
| `Ctrl+b` `s` | 세션 목록에서 전환 |
| `Ctrl+b` `$` | 세션 이름 변경 |

## 스크롤 / 복사
| 키 | 동작 |
|----|------|
| `Alt+u` | 스크롤 모드 진입 |
| (스크롤 중) `k/j` `Ctrl+u/d` `g/G` | 이동 |
| (스크롤 중) `v` → `y` | 선택 → 복사(시스템 클립보드) |
| `q` 또는 `Esc` | 스크롤 모드 종료 |

## 기타
| 키 | 동작 |
|----|------|
| `Ctrl+b` `:` | 명령 입력 |
| `Ctrl+b` `?` | 전체 단축키 도움말 |
| `Ctrl+b` `t` | 시계 |
